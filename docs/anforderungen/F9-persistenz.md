# F9 – Persistenz

- F9.1 Eingaben werden automatisch im localStorage gespeichert und beim Laden wiederhergestellt. *(Test: serialize)*
- F9.2 „Link mit Werten teilen" (bis 1.4: „Link teilen"): Eingaben (nur Abweichungen von den Defaults) als JSON, komprimiert (DEFLATE, `fflate`) und Base64url-kodiert im URL-Hash `#z=…` (bis 1.6: unkomprimiert `#s=…`, wird weiterhin gelesen); entpackt höchstens 256 KB, sonst ungültig (Schutz vor manipulierten Links); ein Link hat Vorrang vor localStorage. Der geteilte Link zeigt auf die kurze Domain `https://wpir.de/` (leitet per 301 auf die Hauptdomain weiter, der Teil nach `#` bleibt erhalten), auf einem lokalen Entwicklungsrechner (localhost, `*.localhost`, `*.test`) auf die eigene Adresse; die Adresszeile behält die aufgerufene Adresse. *(Test: serialize, share)*
- F9.3 JSON-Export als Datei und Import; unbekannte/fehlende Felder werden mit Defaults gemischt, ungültige Dateien abgelehnt. *(Test: serialize)*
- F9.5 Eingabeprüfung (`src/core/validate.ts`) für Link, Import und gespeicherte Eingaben: Zahlen auf Grenzen geklemmt (z. B. Betrachtung ≤ 50 J., Kreditlaufzeit ≤ 50 J., Zeitpunktvergleich ≤ 40, JAZ 0,5–10, sonst ±10⁹), ungültige Monate (Format, Jahr 2000–2150, Inbetriebnahme der Heizung ab 1900) und unbekannte Auswahlwerte → Standardwert, Texte gekürzt (Bezeichnung 200, Bemerkungen 20.000, sonst 2.000 Zeichen). Ersetzte Werte werden über den Ergebnissen gemeldet. Das Formular markiert Werte außerhalb der Grenzen als ungültig. Anlass: Ein präparierter Link/Import konnte den Browser einfrieren (beim Import dauerhaft) oder die Rechnung lahmlegen. *(Test: validate, ui)*
- F9.6 Geteilter Link bei vorhandenen eigenen Eingaben: Hinweis „Geteiltes Szenario geöffnet“; Änderungen aktualisieren nur den Link, nicht den Browser-Speicher, bis „Als meine Eingaben übernehmen“. „Eigene Eingaben laden“ verwirft den Link. Import und Zurücksetzen beenden die Link-Ansicht. Ohne eigene gespeicherte Eingaben verhält sich der Link wie bisher. *(Test: ui)*
- F9.7 Vor „Link mit Werten teilen“ und „Export“ erscheint ein Hinweisfenster: Link bzw. Datei enthalten auch persönliche Angaben (Haushaltseinkommen, Einkommensteuer, Angaben zu Haus und Heizung, Bezeichnung und Bemerkungen) – nur an Personen weitergeben, die sie sehen dürfen. Erst „Link kopieren“ bzw. „Datei (JSON)“ oder „Für KI (Markdown)“ (F35) führt die Aktion aus; „Abbrechen“, Esc oder Klick daneben bricht ab. „Diesen Hinweis nicht mehr anzeigen“ wird im Browser gespeichert (`localStorage`). *(Test: ui)*
- F9.8 Vor „Import“, „Zurücksetzen“ und „Im Rechner öffnen“ einer Variante (F31) warnt ein Fenster, dass die aktuellen Eingaben ersetzt werden (Hinweis auf „Export“ zum Sichern). Erst „Datei wählen“ öffnet die Dateiauswahl, „Zurücksetzen“ setzt zurück bzw. „Übernehmen“ übernimmt die Variante; „Abbrechen“, Esc oder Klick daneben bricht ab. Diese Warnung lässt sich nicht abschalten (ersetzt die früheren Browser-Rückfragen beim Zurücksetzen und bei der Variantenübernahme). *(Test: ui)*
